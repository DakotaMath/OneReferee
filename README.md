# PDF Spacer Notes

Write on PDFs with a pen display and open up blank space anywhere on a page, between any two
lines, by dragging — the way OneNote's **Insert Space** works. Built for a Huion Kamvas 16 (Gen 3)
on Windows, in Microsoft Edge or Chrome. Runs fully offline in the browser; nothing is uploaded.

## Run locally

Requires Node 22+.

```sh
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests (Vitest)
npm run build    # static site in dist/
npm run lint
```
